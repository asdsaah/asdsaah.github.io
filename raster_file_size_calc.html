Raster File Size Calculator

Description: Use this tool to estimate the size of a raster before you create it, just give it a study area, resolution, and cell value type. Web based verion of a CLI tool (Link) I also developed.

Instructions: Input your study area size in terms of squared kilometers, area of pixel, and pixel data type.

Citation: Saah, A. (2026). Raster File Size Calculator [Web Application]. Retrieved from https://github.com/asdsaah/RasterFileSizeCalc
Area -> Abbreviation
Acre -> acre
Hectare -> ha
Square Meter -> sqm
Square Kilometer -> sqkm
Data Type -> Bytes -> Range
byte -> 1 -> 0 to 255
int8 -> 1 -> -128 to 127
int16 -> 2 -> -32768 to 32767
uint16 -> 2 -> 0 to 65535
uint32 -> 4 -> 0 to 4294967295
int32 -> 4 -> -2147483648 to 2147483647
float32 -> 4 -> -3.40282e+38 to 3.40282e+38
float64 -> 8 -> -1.79769e+308 to 1.79769e+308
cint16 -> 4 -> -32768 to 32767 (per comp)
cint32 -> 8 -> -2147483648 to 2147483647 (per comp)
cfloat32 -> 8 -> -3.402e+38 to 3.402e+38 (per comp)
cfloat64 -> 16 -> -1.79e+308 to 1.79e+308 (per comp)
Example Inputs:
Landsat 8/9: Area: 35000 | Units: sqkm | Pixel Res (m): 30 | Type: int16 | Bands: 7
Sentinel-2: Area: 10000 | Units: sqkm | Pixel Res (m): 10 | Type: uint16 | Bands: 13
NAIP: Area: 1000 | Units: sqkm | Pixel Res (m): 1 | Type: byte | Bands: 4
Planet SkySat: Area: 400 | Units: sqkm | Pixel Res (m): 0.5 | Type: uint16 | Bands: 4
